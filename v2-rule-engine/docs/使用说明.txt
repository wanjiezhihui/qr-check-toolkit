======================================================================
  二维码标签校验系统  P1 单机版  v2.0.0  使用说明
======================================================================

一、这是什么
----------------------------------------------------------------------
打印出来的二维码标签，在贴出去之前逐张扫一遍，系统按你事先配好的
"料号规则"校验内容对不对、有没有重复，并按严重程度处置：

    放行   → 绿字 + 一声短响
    提醒   → 黄字 + 两声，按确认键才继续
    拦截   → 红字 + 三声急响，不通过、须重扫
    锁码   → 这个码进锁定名单，需要密码解锁
    锁屏   → 整个界面锁死，需要密码解锁

跟上一版（只验重）的区别：这一版多了【内容规则校验】——
每个料号配一条规则，规则下挂任意多条校验条件，内容不符就当场拦。


二、装与启动
----------------------------------------------------------------------
目标电脑不需要装 Python、不需要联网、不需要任何运行库。

    QRCheck.exe          双击即用（首选）
    QRCheck-portable\    文件夹版，启动更快、杀软误报概率更低
                         要整个文件夹一起拷，双击里面的 QRCheck.exe

首次启动会在同目录下自动建 data\ 文件夹，所有数据都在里面。
建议把整个文件夹放在 D 盘（不要放桌面，桌面常被清理策略扫）。

只支持 64 位 Windows 10 / 11。Win7 跑不了。


三、第一次使用（三步）
----------------------------------------------------------------------
第 1 步  设解锁密码
        右上角「设置 F10」→「设置解锁密码」。
        ⚠ 必须设！否则一旦触发锁屏就解不开，只能重启电脑。
        密码只存哈希不存明文，忘了只能删 data\ 库重来。

第 2 步  建规则（这是核心）
        「规则管理 F3」→「新建规则」

        ┌ 料号 ─────────────────────────────────────────────
        │ 规则的唯一标识，建议和 ERP/MES 的料号完全一致。
        │ 输入时会实时提示：
        │   ✓ 绿色  料号可用
        │   ⚠ 黄色  该料号已有规则，保存会覆盖（会显示原规则名和时间）
        │   ⚠ 橙色  料号里有空格/中文标点（扫码枪带进来的），建议清掉
        │ 输入前几位会联想历史料号，可直接下拉选。
        └──────────────────────────────────────────────────

        ┌ 识别方式 ─────────────────────────────────────────
        │ 决定"扫到的码怎么认出是哪个料号"。
        │   前缀    码开头是这段字符 → 归这个料号（最常用）
        │   分段    按分隔符切开，第 N 段等于某值
        │   正则    高级用法，需谨慎
        │   完全相等 整个码完全一致
        │
        │ ⚠ 故意不支持「包含」：用"包含 2026"会把别的料号的码
        │   先吸过来，然后按错的规则判"通过"——比不校验更危险。
        └──────────────────────────────────────────────────

        ┌ 校验条件（可加任意多条）──────────────────────────
        │ 每条条件选类型 + 填值。11 种类型：
        │   包含子串 / 不包含子串 / 开头是 / 结尾是 / 完全等于
        │   正则匹配（危险，界面会标红警告）
        │   长度在区间          如 20-30
        │   只允许这些字符      如 A-Z0-9%/+*-  能抓中文/全角混入
        │   分段取值比对        ★ 关键：按分隔符切段后精确比对
        │   分段日期有效        抓日期写错/过期标签
        │   两段日期一致        ★ 抓"同一张标签上两处日期对不上"
        │
        │ 每条可单独设：必须/可选、取反、不满足时的动作、提示文案。
        │ 提示文案是写给现场看的人话，比如"料号段不符，请确认是否混料"。
        │
        │ 规则级还能设条件关系：全部满足 / 任一满足 / 至少N条。
        └──────────────────────────────────────────────────

        ┌ 动作 ─────────────────────────────────────────────
        │   条件全过    通常选「放行」
        │   条件不符    通常选「拦截」
        │   判为重复    通常选「锁码」
        │ 验重范围：全局（一码全网唯一）/ 仅本料号内 / 不验重
        │ 优先级：数字小的先匹配（前缀有重叠时用）
        └──────────────────────────────────────────────────

第 3 步  建完必须验证
        「规则测试器 F8」或规则编辑页的「测试这条规则」
        贴一个真实码进去，逐条看哪个条件通过、哪个没过，再下判定。
        ⚠ 建规则不验证，等于没建——配错了要等现场出事才发现。


四、批量导入（每天几十个料号必用）
----------------------------------------------------------------------
「规则管理 F3」→「下载导入模板」→ 用 Excel 打开填写 → 「导入 Excel/CSV」

模板规则是【一行一个条件，同一料号多行自动合并成一条规则】：

    料号          识别方式  识别值        条件类型      条件值
    3000000003    前缀      3000000003    包含子串      3000000003
    (留空)                                包含子串      8888
    (留空)                                结尾是        008

  ★ 续行的"料号"留空即可，会自动归到上一行的料号。
  ★ 规则级字段（识别方式/动作/验重范围）同一料号只在第一行填一次。

支持 .xlsx 和 .csv。导入前会先做【预检】，分四类列出：
    新增 / 覆盖 / 冲突（识别式与别的料号重叠）/ 格式错
冲突和格式错的不会被导入，看清楚再点确认。

也可以「导出当前规则」改成 CSV，改完再导回来。


五、日常操作
----------------------------------------------------------------------
  F2   撤销上一条（扫错了用，撤销后把那张标签重扫一次）
  F3   规则管理
  F4   导出扫码明细 CSV（Excel 直接开，带 BOM 不乱码）
  F5   导出唯一码 TXT（一行一个，用于交付或核对张数）
  F6   生成校验报告 TXT（含总体统计 + 按料号汇总 + 问题清单）
  F8   规则测试器
  F9   声音开关
  F10  设置
  Esc  清空当前显示

左上角「料号」下拉默认是「▶ 自动识别」，按各规则识别式自动路由。
如果某个工位固定只做一两种料号，可以选死料号，速度更快、零歧义。
选中后如果扫到不属于该料号的码，会提示"疑似混料"。

「批次/卷号」填上之后，统计、导出、报告都只算这个批次，换卷时改一下即可。


六、⚠ 开工前必做的一件事
----------------------------------------------------------------------
很多扫码枪出厂默认开着「同码延时输出 / Duplicate Code Check」——
同一个码几秒内扫第二次，枪根本不往外发数据。那样重码永远看不到报警。

自检法：拿同一张标签连扫两次，两次界面都有反应才算正常。
第二次没动静 → 去枪的设置里把重复码相关项设为 0，或恢复出厂后重设。

另外把输入法切成英文，否则中文输入法会吃掉字符。


七、锁屏能锁到什么程度（必须说实话）
----------------------------------------------------------------------
能拦住：Alt+F4、Alt+Tab、Alt+Esc、Win 键、Ctrl+Esc、
        Ctrl+Shift+Esc、PrintScreen、关闭按钮

拦不住（Windows 系统保留，任何用户态程序都拦不住）：
        Ctrl+Alt+Del、Win+L、UAC 安全弹窗、注销/重启/断电

B 档看门狗（设置里可开）能额外解决"任务管理器结束进程"——
主程序被杀后 3 秒内自动重启并保持锁定态。

要真正锁死（连 Ctrl+Alt+Del 都出不去），需要：
  C 档 Windows 受控访问（Assigned Access），把该账号锁死在单一应用。
  需 Win10/11 企业版/教育版，家庭版不支持，要 IT 配合配置。

默认是 A 档（纯软件），挡得住误操作和普通操作工，挡不住会开任务管理器的人。


八、数据在哪、怎么备份
----------------------------------------------------------------------
  data\qr_rules.db     规则 + 扫码记录 + 锁定名单 + 审计日志（SQLite）
  data\exports\        默认导出目录
  data\run\            看门狗运行时文件
  data\crash.log       崩溃日志（现场报"打不开"时先看这个）

备份就复制 data\ 整个文件夹。
每条扫码立即落盘，拔电、任务管理器强杀都不会丢已扫记录。
建议每卷扫完按 F4 导一次存档，再对一下张数。


九、这一版没做什么（说清楚，别到时候问）
----------------------------------------------------------------------
1. 【联机版还没有】本版是单机版。多终端跨机验重要等 P2：
   中心服务端 + 各终端接入 + 断网降级。
   现在各终端的数据是各自独立的，A 机器扫过的码 B 机器不知道。
2. 【串口扫码枪不支持】本版走 USB HID 键盘模式（枪插上就是键盘）。
   如果现场是串口枪（设备管理器里出现 COMx），告诉我，加回来不难。
3. 【只管"扫过的有没有问题"，不管"该扫的有没有漏扫"】
   二维码破损读不出时枪不会报错、就是没反应。
   建议每卷扫完先导一次存档，再核对张数。


十、出问题怎么办
----------------------------------------------------------------------
  双击没反应        看 data\crash.log；或先换 QRCheck-portable 文件夹版
  杀毒软件报毒       PyInstaller 打包的 exe 有自解压特征，360/火绒有时报可疑。
                     不是病毒，加白名单即可；嫌麻烦就用文件夹版。
  首次启动慢         单文件版要解压 + 杀软扫描，3-5 秒正常，不是卡死。
  扫了没反应         ① 输入法是不是英文 ② 枪是不是开了同码延时
                     ③ 窗口是不是被别的程序挡住了
  所有码都被拦截     还没建规则。去「规则管理 F3」建。
  码被判"未建规则"   该料号的规则没建、或识别式写错了。
                     用「规则测试器 F8」贴这个码进去看能不能命中。
  锁屏后解不开       用设置的密码。密码忘了只能删 data\qr_rules.db 重来
                     （规则和记录会一起没，提前备份）。
