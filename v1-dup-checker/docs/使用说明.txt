==============================================================
  二维码标签验重工具  v1.1  使用说明
==============================================================

一句话：扫码枪逐张扫，重复的立刻声光报警，全部记录自动落库，
        随时导出 CSV / TXT / 汇总报告。

支持两类扫码枪：
  · USB 键盘模式（HID）—— 绝大多数枪，插上即用
  · 串口模式（COM 口）  —— USB 虚拟串口 / RS232 转 USB


--------------------------------------------------------------
一、先弄清：你的扫码枪是哪种接法
--------------------------------------------------------------

  两种枪外观差不多，但程序接收数据的方式完全不同，选错了会「扫了没反应」。

  判断方法：把枪插上电脑，打开「设备管理器」看一眼——

    多出来的是「键盘」           → USB 键盘模式（HID）
    多出来的是「端口 COMx」      → 串口模式

  程序里按 F10 切换，默认是键盘模式。
  · 键盘模式：什么都不用配。
  · 串口模式：要选 COM 口 + 波特率（扫码枪出厂多为 9600-8-N-1）。
    连错了会提示「串口打开失败」，提示里会列出本机现有 COM 口，
    照着换一个再试即可。


--------------------------------------------------------------
二、开工前必须做的检查（不做会白扫）
--------------------------------------------------------------

【1】键盘模式下：扫码枪必须关闭「重复码过滤」  ← 最关键

  很多扫码枪出厂默认开着「Duplicate Code Check / 同码延时输出」，
  意思是同一个码在 N 秒内扫第二次，枪根本不会往外发数据。
  如果这样，重复码你永远看不到报警——验重直接失效。

  处理方法：
    · 翻扫码枪说明书，把「重复码 / Duplicate / Same Code Delay」
      相关设置改为 0 或关闭；
    · 或先扫说明书上的「恢复出厂设置」条码，再改这一项。

  自检方法（强烈建议做一次）：
    拿同一张标签，连扫两次。
      → 两次界面都有反应  = 正常，可以开工
      → 第二次毫无反应    = 扫码枪在吞重复码，必须改设置

  ※ 串口模式不走键盘逻辑，但若枪本身设了重复码过滤，同样要从枪里关掉。


【2】键盘模式下：输入法必须切到英文

  中文输入法会截走字符，导致扫出来的内容残缺。
  任务栏右下角确认是「英」状态。
  （串口模式不受输入法影响）


【3】扫码枪必须带「回车」后缀

  本工具靠回车（CR/Enter）判断一张码扫完。
  键盘模式：绝大多数枪默认就发回车。若扫完没结果，
            去枪的设置里把「后缀 / Suffix / Terminator」设为 CR(Enter)。
  串口模式：同理，终止符设为 CR 或 CR+LF。


--------------------------------------------------------------
三、开始扫码
--------------------------------------------------------------

  双击 QRCheck.exe 打开程序。

  注意：exe 是单文件打包，首次启动需要 3~5 秒解压，
        稍等窗口就会出来，不是卡死。

  第 1 步：按 F7 把批次名改成当前卷号，例如「卷1」「卷2-A」。
           每换一卷就改一次，统计和导出才分得清。

  第 2 步：用鼠标点一下程序窗口，确保它在最前面。

  第 3 步：开始一张一张扫。

  界面怎么读：
    · 绿色大字「首 次 通 过」      → 这张没扫过，正常，一声短提示音
    · 红色大字「重 复 ！」        → 这张重复了，三声急促警报
        顶部红条会告诉你：这个码第一次出现在第几张、什么时间、
        如果是跨卷重复，还会显示它第一次是在哪一卷。

    · 三个数字：总扫描 / 唯一码 / 重复
    · 右侧「重复清单」：所有重复的码，按出现次数汇总，一眼看出要重打哪几张
    · 下方「最近扫描流」：刚才扫过的一条条流水

  扫错或误扫了 → 按 F2 撤销上一条


--------------------------------------------------------------
四、扫完导出
--------------------------------------------------------------

  F4  导出 CSV        Excel 可直接打开，逐条含：
                      序号 / 二维码内容 / 扫描时间 / 该码第几次出现 / 状态 / 批次
                      适合：人工复核、存档

  F5  导出 TXT        只含唯一码，每行一个
                      适合：直接丢给系统导入、贴到别的表里

  F6  导出汇总报告    统计 + 每个重复码的完整出现流水
                      适合：直接当验重报告交上去

  文件默认保存到 data\export\ 目录下，文件名自动带批次名和时间戳。


--------------------------------------------------------------
五、部署到别的电脑（客户现场）
--------------------------------------------------------------

  ★ 目标电脑不需要装 Python，不需要装任何运行库，不需要联网。

  做法：把 QRCheck.exe 一个文件拷过去，双击就能运行。

  首次运行会自动在 exe 同目录建一个 data 文件夹，里面是：
    data\qr_records.db    SQLite 数据库（所有扫码记录都在这里）
    data\snd_*.wav        报警提示音（程序自动生成）
    data\export\          导出文件默认放这里

  ★ data 文件夹不要删、不要和 exe 分开。

  对目标电脑的要求：
    · 64 位 Windows 10 / 11
      （Windows 7 跑不起来——内置的 Python 3.13 已不支持 Win7）
    · 就是一台普通办公/车间电脑即可，配置无特殊要求

  ⚠ 杀毒软件可能误报
    exe 是用 PyInstaller 打包的，部分国产杀软（360、火绒等）
    会对这类「自解压型 exe」报可疑。这不是病毒，是打包方式的特征。
    处理：把 QRCheck.exe 加入杀软信任/白名单，或找 IT 报备放行。
    如果这台机器不方便加白名单，改用下面的「文件夹版」。

  ⚠ 文件夹版（备选）：QRCheck-portable 目录
    这是一个文件夹，双击里面的 QRCheck.exe 运行。
    优点：启动快（不用解压，1 秒内就起来）、被杀软误报的概率更低。
    缺点：要整个 QRCheck-portable 文件夹一起拷，不能只拷单个 exe。
    两个版本功能完全一样，任选其一。

  【交付目录一览】
    QRCheck.exe          单文件版 —— 拷这一个过去就行（首选）
    QRCheck-portable\    文件夹版 —— 备选，整个文件夹一起拷
    data\                运行后自动生成，所有扫码记录都在这里
    使用说明.txt         本文档
    启动.bat             双击也能启动（自动挑可用的那个）


--------------------------------------------------------------
六、数据存在哪
--------------------------------------------------------------

  data\qr_records.db      SQLite 数据库

  每扫一张立刻写盘，中途断电、程序被关，已扫的记录都不会丢。
  ★ 这个文件不要删、不要移动。

  同一天重新打开程序会自动接着当前批次的记录继续（批次名默认按日期）。
  如果要接着昨天的批次，按 F7 把批次名改回原来的名字即可。


--------------------------------------------------------------
七、快捷键
--------------------------------------------------------------

  F2   撤销上一条（扫错了用）
  F3   手动补录（扫码枪扫不出的码，人工输入/粘贴）
  F4   导出 CSV
  F5   导出 TXT（唯一码）
  F6   导出汇总报告
  F7   修改批次名
  F8   窗口置顶开关（防误点到别的窗口）
  F9   声音报警开关
  F10  输入源切换（键盘模式 / 串口模式）
  Esc  退出（会先提示当前统计，防误关）


--------------------------------------------------------------
八、常见问题
--------------------------------------------------------------

Q：扫了半天，界面一点反应都没有
A：按顺序查：
   ① 输入源选对了吗？按 F10 看当前是「键盘」还是「串口 COMx」，
      和设备管理器里的一致吗？
   ② 键盘模式：焦点不在本窗口（看顶部有没有「⚠ 窗口未激活」警告）
   ③ 键盘模式：输入法还是中文
   ④ 扫码枪没配回车后缀
   ⑤ 串口模式：波特率不对，换成 9600 再试

Q：F10 里提示「未检测到串口」
A：说明这台电脑当前没有任何 COM 口。
   要么枪是键盘式的（那就选键盘模式），
   要么是串口枪但驱动没装（装一下 USB 转串口驱动，或换数据线）。

Q：顶部出现「⚠ 窗口未激活 · 扫码无效」
A：焦点跑到别的程序去了。点一下本窗口即可。
   长期作业建议按 F8 开启置顶。

Q：一个明显是新的码，却报重复
A：两种可能：
   ① 右下角「忽略大小写」被勾上了——勾上后 ABC 和 abc 会被当成同一个码
   ② 这确实是跨卷重复。看顶部红条里的「首次出现于 第 X 张」确认。

Q：跨卷扫会不会误报？
A：不会，反而是重点。验重是跨批次全局生效的——
   上一卷出现过的码，这一卷再出现同样会报警，这正是防重打的关键。

Q：一张标签上有多个二维码怎么办？
A：本工具按「每次扫出的内容」整体判断，一次扫一个码即可，
   各自独立记录、各自验重。

Q：不小心关了程序，扫的数据还有吗？
A：有。记录实时写进数据库，重开就能看到。


--------------------------------------------------------------
九、能力边界（先说清楚，免得到时候误会）
--------------------------------------------------------------

  · 本工具验的是「扫过的码里有没有重复」，
    不验「该扫的有没有漏扫」。
    漏扫要靠卷宗数量核对，工具管不了。

  · 二维码本身破损、脏污、反光导致枪读不出来时，
    扫码枪不会报错，就是没反应——这个需要人工留意，
    建议每卷扫完对照数量核一下。

  · 建议每卷扫完立刻按 F4 导一次 CSV 存档，
    不要等全部扫完再导。多一份存档多一份底。
